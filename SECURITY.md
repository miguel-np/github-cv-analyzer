# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.6.x   | :white_check_mark: |
| < 0.6   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public issue. Instead, report it privately to the maintainers.

1. Go to the [Security Advisories](https://github.com/miguel-np/github-cv-analyzer/security/advisories/new) page
2. Click **Report a vulnerability**
3. Describe the issue with as much detail as possible:
   - Affected version(s)
   - Steps to reproduce
   - Potential impact
   - Suggested fix (if any)

You will receive a response within **48 hours**. If the vulnerability is accepted:

- A fix will be developed and released as soon as possible
- You will be credited in the release notes (unless you prefer to remain anonymous)
- The advisory will be published after the fix is released
